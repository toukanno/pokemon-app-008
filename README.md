# ポケットモンスター ファイアレッド風ミニRPG

[PokeAPI](https://pokeapi.co/) のデータを使った、ファイアレッド風のブラウザミニRPGです。
ビルド不要のバニラ JavaScript 製で、`index.html` をブラウザで開くだけで遊べます。

※ ファンメイドの非公式ミニゲームです。

## あそびかた

1. タイトル画面で「さいしょから」を選ぶ
2. オーキド博士から御三家（フシギダネ・ヒトカゲ・ゼニガメ）を1匹選ぶ
3. フィールドを矢印キー（または画面の十字キー）で移動
4. 草むらを歩くと野生ポケモンが出現してバトル開始
5. モンスターボールで捕まえて仲間を増やそう（手持ち6匹、あふれた分はボックスへ）
6. ポケモンセンター（赤い屋根のタイル）に乗ると全回復＆道具補給

## ゲームの仕様

- **マップ**: 浅い草むら（ポッポ・コラッタなど Lv.2〜5）と深い草むら（ピカチュウ・ナゾノクサなど Lv.5〜8）の2エリア
- **バトル**: たたかう／バッグ／ポケモン（交代）／にげる。すばやさで行動順が決まるターン制
- **ダメージ計算**: 第3世代準拠の簡易式（タイプ相性・タイプ一致1.5倍・急所あり）
- **技**: ファイアレッド・リーフグリーンのレベルアップ技から取得。レベルアップで新しい技を習得
- **捕獲**: 種族ごとの捕捉率と残りHPから成功率を計算
- **経験値**: 敵を倒すと経験値を獲得してレベルアップ
- **セーブ**: localStorage に自動セーブ（バトル後・回復時など）。「つづきから」で再開

## 操作方法

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD / 画面の十字キー |
| メッセージ送り | Z / Enter / Space / クリック / Aボタン |

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構造（タイトル・御三家選択・フィールド・バトル・パーティ） |
| `style.css` | GBA 風スタイル（ドット絵タイル・ウィンドウ枠） |
| `app.js` | ゲームロジック（マップ・エンカウント・バトル・捕獲・セーブ） |

ポケモンのデータ（種族値・技・ドット絵スプライト・日本語名）はすべて
PokeAPI からブラウザ上で直接取得します（API キー不要）。
