# ポケモン図鑑アプリ

[PokeAPI](https://pokeapi.co/) を使ったポケモン図鑑の Web アプリです。
ビルド不要のバニラ JavaScript 製で、`index.html` をブラウザで開くだけで動きます。

## 機能

- 第1〜第9世代のポケモンを世代切り替えで一覧表示
- 日本語の名前・タイプバッジ付きカード表示
- 名前（日本語/英語）・図鑑番号でのリアルタイム検索
- カードをクリックすると詳細モーダルを表示
  - 公式アートワーク、分類、図鑑説明（日本語）
  - たかさ・おもさ・とくせい（隠れ特性表示付き）
  - 種族値のバーグラフ

## 使い方

```bash
# そのまま開く
open index.html

# またはローカルサーバーで起動
npx serve .
# → http://localhost:3000
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ構造（ヘッダー・グリッド・モーダル） |
| `style.css` | スタイル（タイプ別カラー、レスポンシブ対応） |
| `app.js` | PokeAPI からのデータ取得・描画ロジック |

データはすべて PokeAPI からブラウザ上で直接取得します（API キー不要）。
取得結果はメモリ上にキャッシュされ、世代の再切り替え時は再リクエストしません。
