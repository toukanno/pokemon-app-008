# ポケモン図鑑 ファイアレッド

[PokeAPI](https://pokeapi.co/) を使った、ファイアレッド仕様のポケモン図鑑 Web アプリです。
ビルド不要のバニラ JavaScript 製で、`index.html` をブラウザで開くだけで動きます。

## 機能

- カントー地方 151 匹（ファイアレッドの図鑑範囲）を一覧表示
- ファイアレッド・リーフグリーン版の GBA ドット絵スプライトを使用
- 図鑑説明文はファイアレッド版を優先して表示（日本語）
- 赤基調の GBA 風 UI（ドット枠ウィンドウ・DotGothic16 ピクセルフォント）
- 名前（日本語/英語）・図鑑番号でのリアルタイム検索
- カードをクリックすると詳細を表示
  - 分類、図鑑説明、たかさ・おもさ・とくせい（隠れ特性表示付き）
  - 種族値のバーグラフ

## 使い方

```bash
# そのまま開く
open index.html

# またはローカルサーバーで起動
npx serve .
# → http://localhost:3000
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ構造（ヘッダー・グリッド・モーダル） |
| `style.css` | GBA 風スタイル（タイプ別カラー、レスポンシブ対応） |
| `app.js` | PokeAPI からのデータ取得・描画ロジック |

データはすべて PokeAPI からブラウザ上で直接取得します（API キー不要）。
取得結果はメモリ上にキャッシュされます。
